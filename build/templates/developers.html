JSON API

Every book and chapter is available as a JSON file you can fetch straight from your app. Cross-origin requests are allowed.

GET /api/books.jsonList of all 66 books
GET /api/{book}.jsonA whole book, e.g. /api/ruth.json
GET /api/{book}/{chapter}.jsonOne chapter, e.g. /api/john/3.json

Book slugs are lowercase with dashes: genesis, 1-samuel, psalms, song-of-solomon, 1-john. Each book also has its standard USFM code (GEN, PSA, JHN…).

Example

const res = await fetch("https://readable.bible/api/john/3.json");
const chapter = await res.json();
const verse = chapter.verses.find(v => v.verse === 16);
console.log(verse.text);

A chapter looks like this (shortened):

{
  "name": "Readable English Bible",
  "license": "{{LICENSE_NAME}}",
  "book": { "name": "John", "slug": "john", "usfm": "JHN", "testament": "NT", "chapters": 21 },
  "chapter": 3,
  "verses": [
    { "verse": 16, "text": "For God so loved the world…" }
  ],
  "previous": { "book": "john", "chapter": 2, "url": "…" },
  "next": { "book": "john", "chapter": 4, "url": "…" }
}

Verses with a translator note include a "note" field. Lines of poetry are separated by \n.
